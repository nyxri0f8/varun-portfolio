# Varun S — Portfolio

**Live:** https://varun-portfolio-lac.vercel.app

Scroll-driven portfolio for **Varun S** — AI · Embedded Systems · Full-Stack.

Every section is a scene from the portfolio film: it pins to the screen and animates as you scroll
(GSAP ScrollTrigger + Lenis smooth scroll). Landscape screens get the 16:9 layout with the scene's
colours bleeding to the edges; phones get a dedicated portrait layout. Tap **Sound** for the voiceover
and music, or **Film** for the full 75-second video.

Static site — no build step. Deployed on Vercel.
